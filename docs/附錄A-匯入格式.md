# 附錄 A — 匯入格式規格

本工具支援兩大類匯入：**影像類**（走 OMR 管線）與**文字類**（直接解析）。
本文件說明文字類格式的欄位定義。所有文字檔請以 **UTF-8** 儲存（也接受 UTF-8 BOM、UTF-16、Big5／CP950、GB18030）。

---

## 一、支援的副檔名

| 類別 | 副檔名 | 需要 Tesseract | 說明 |
| --- | --- | --- | --- |
| 影像 | `.pdf` | 是 | 多頁 PDF 逐頁轉圖後辨識 |
| 影像 | `.jpg` `.jpeg` `.png` `.tif` `.tiff` | 是 | 單張樂譜掃描／拍照 |
| 文字 | `.csv` `.tsv` | 否 | 表格式，一列一拍或一列一小節 |
| 文字 | `.txt` | 否 | 表格式或**原稿式**（見第四節） |
| 文字 | `.json` | 否 | 本工具匯出的完整結構，資訊無損 |
| 其他 | `.son` | 否 | 先當 UTF-8 文字／CSV／JSON 嘗試解析 |

單檔上限 **200 MB**。副檔名、MIME 與檔頭簽章三重驗證都通過才會受理。

---

## 二、JSON（最完整，建議用於備份與轉移）

這是「匯出 → JSON」的同一種格式，匯入時資訊無損（含信心值與拍位）。

```json
{
  "title": "春風輕唱",
  "lyricist": "作詞者",
  "composer": "作曲者",
  "key": "C",
  "timeSignature": "4/4",
  "tempo": 92,
  "measures": [
    {
      "number": 1,
      "lineIndex": 0,
      "linePosition": 1,
      "chordText": "C",
      "noteText": "1 2 3 5",
      "lyricText": "春風輕唱",
      "beats": [
        { "beat": 1, "note": "1", "lyric": "春", "chord": "C", "duration": "quarter", "confidence": 1.0 },
        { "beat": 2, "note": "2", "lyric": "風", "chord": "",  "duration": "quarter", "confidence": 1.0 },
        { "beat": 3, "note": "3", "lyric": "輕", "chord": "",  "duration": "quarter", "confidence": 1.0 },
        { "beat": 4, "note": "5", "lyric": "唱", "chord": "",  "duration": "quarter", "confidence": 1.0 }
      ]
    }
  ]
}
```

- `beats` 可省略：省略時會依 `noteText` / `lyricText` / `chordText` 自動展開。
- `lineIndex` / `linePosition` 可省略：省略時依「每行 3 小節」自動重排。
- `confidence` < 0.7 的拍位會在介面標為**低信心**，並寫入 MusicXML 註記。

## 三、CSV / TSV / 表格式 TXT

第一列為欄位標題。**欄位名稱中英皆可**，順序不限，未用到的欄位可省略。

### 欄位別名對照

| 欄位 | 可用名稱 |
| --- | --- |
| 小節編號 | `measure`、`小節`、`小節編號`、`bar` |
| 拍序 | `beat`、`拍`、`拍序`、`拍位` |
| 簡譜 | `note`、`簡譜`、`音`、`音符`、`jianpu` |
| 歌詞 | `lyric`、`歌詞`、`詞` |
| 和弦 | `chord`、`和弦` |
| 時值 | `duration`、`時值` |
| 信心 | `confidence`、`信心`、`信心值` |

### 3-1 一列一拍（最精確）

```csv
measure,beat,note,lyric,chord,duration,confidence
1,1,1,春,C,quarter,1.0
1,2,2,風,,quarter,1.0
1,3,3,輕,,quarter,1.0
1,4,5,唱,,quarter,1.0
2,1,5,著,G,quarter,1.0
2,2,3,歌,,quarter,1.0
2,3,2,謠,,quarter,1.0
2,4,1,-,,quarter,1.0
```

### 3-2 一列一小節（較省事）

`note` 欄位放整句、以空白分隔；`lyric` 放整句歌詞。

```csv
小節,和弦,簡譜,歌詞
1,C,1 2 3 5,春風輕唱
2,G,5 3 2 1,著歌謠
3,F,6 5 4 3,星光落在
4,Am,3 2 1 -,窗前
```

### 3-3 metadata 列（選用）

在標題列**之前**可用單獨的列指定樂曲資訊，每列一項：

```
歌名：春風輕唱
作詞：某某
作曲：某某
1=C
4/4
♩=92
小節,和弦,簡譜,歌詞
...
```

可辨識的寫法：`歌名／曲名／title`、`作詞／詞／lyricist`、`作曲／曲／composer`、
`1=C`（調號）、`4/4`（拍號）、`速度：92`／`♩=92`／`tempo: 92`（速度）。
未指定時預設 `1=C`、`4/4`、`♩=90`，歌名取檔名。

## 四、原稿式 TXT（最接近手寫譜的寫法）

以**三行一組**書寫：和弦行 → 簡譜行 → 歌詞行，組與組之間空一行。
用 `|` 標示小節線。

```
月光小夜曲
作詞：測試
作曲：測試
1=G
4/4
♩=76

C        G       Am      F
1 2 3 5 | 5 6 5 3 | 6 5 3 2 | 1 - - -
月光灑落 | 在小河邊 | 微風輕輕 | 吹

Am       Em      F       G
3 3 2 1 | 2 2 1 6, | 5, 6, 1 2 | 3 - - -
我在等你 | 回頭看我 | 一眼就好 | 了
```

### 對齊規則

- **簡譜行**以 `|` 切成小節；沒有 `|` 時每 4 個記號自動切一小節。
- **歌詞行**有 `|` 就照切；沒有 `|` 時按每小節的拍數逐字分配。
- **和弦行**：若和弦數量剛好等於該組的小節數，就**一小節一個和弦**；
  也可以寫成 `C | G | Am | F` 明確對應。
- 三行的小節數建議一致；不足的部分會留空，不會亂猜。

> 注意：`,`（低八度記號）**不會**被誤判成 CSV 分隔符；
> `|` 一律視為小節線，不會被當作欄位分隔。

## 五、`.SON` 檔案

本版**沒有** `.SON` 二進位格式的正式規格，因此處理方式是：

1. 先嘗試以 UTF-8／UTF-16／Big5／GB18030 解碼成文字。
2. 解碼成功 → 依 JSON／CSV／TSV／原稿式規則解析。
3. 解碼失敗或結構無法辨識 → 明確顯示**「格式無法解析」**並附上原因。

**本工具不會為未知二進位格式猜測內容或產生假結果**（規劃書 8.3）。
遇到此情況，請用原軟體匯出 CSV／TSV／JSON 後再匯入。

## 六、常見錯誤訊息對照

| 訊息 | 原因與處理 |
| --- | --- |
| `不支援的副檔名 .xxx` | 檔案類型不在白名單；請轉存為支援格式 |
| `PDF signature 驗證失敗：檔案開頭不是 %PDF-` | 副檔名與實際內容不符，或檔案損壞 |
| `JPEG signature 驗證失敗：檔案開頭不是 FF D8 FF` | 同上；請用影像軟體重新另存 |
| `格式無法解析：找不到可辨識的欄位標題、分隔欄位或原稿式結構` | 檔案內容不符本附錄任一格式；請對照第三或第四節調整 |
| `內容不是可辨識的 UTF-8／UTF-16／Big5 文字結構` | 未知二進位檔；請改用文字格式匯出 |
| `OMR 引擎不可用，因此不會產生任何識別結果` | 未安裝 Tesseract；見 README 第三節 |
| `未安裝中文語言資料（chi_tra／chi_sim）` | 中文歌詞會辨識不準；放入 `chi_tra.traineddata` 後重新整理引擎 |
