# 離線驗收清單（對應規劃書 10.2 驗證矩陣）

逐項照做即可確認本工具在你的環境中符合規劃要求。
建議在**全新的資料目錄**下驗收：`SHEETMUSIC_DATA_DIR=/tmp/驗收 python launcher.py --no-browser`。

「已在開發環境驗證」欄位標示的是本專案交付前已實測通過的項目；
標示「需你的環境確認」者與你的作業系統／權限／磁碟狀態有關，請在自己機器上跑一次。
